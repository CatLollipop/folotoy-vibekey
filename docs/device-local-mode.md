# 设备本地运行模式与边缘提示（0.3.2候选）

长按右侧上键进入“运行模式”，可在“AI 助理”和“连接电脑”之间切换；第三行“返回”只关闭菜单。AI 助理是设备独立直连云服务，连接电脑恢复相伴模式。上下键短按移动，高亮表示正在选择；对勾独立标识当前实际模式。确认键短按选择，长按确认键返回；30秒无操作自动退出。

长按上键这次由固件消费，替代旧的dictation/translation/subtitle长上切换；短上延迟到松开判定，避免一次长按还向Mac泄漏短按动作。独立模式短上清历史、短下取消、按住确认键说话/忙时打断重录，长下保留无线网络列表；相伴模式长下保留原Mac会话/离线网络入口。没有新增左侧功能键。

## 模式检查

本地菜单与线协议共用`ib_assistant_mode_request`的检查/持久化/安全重启路径：相同模式选择只返回；切独立前要求Wi-Fi和有效云端profile；忙、同步配置、不可用、保存失败时不切换、不假报成功。选择新模式保存后显示“正在切换模式 / 设备即将重新启动”，由app延迟安全重启。具体输入/NVS逻辑在`ib_run_menu`及助手模块，UI不自行改运行模式。

UI提示包括“请先停止当前对话”“请先在电脑配置无线网络”“请先在电脑同步云端配置”“模式保存失败，请重试”“助手暂不可用”和“正在同步配置 / 请稍后切换模式”。当前模式与选择高亮相互独立，失败保留菜单。

## 菜单优先级和缓存

`ib_run_menu纯手势状态机 → ib_app本地菜单owner → ib_ui_run_mode_menu → 现有LIST对象`。没有新建完整页面或大缓冲；`s_ctx.list`继续保存最后的Mac列表，LIST仅在本地菜单active时用三行固定资源渲染。

菜单打开后，Mac的state只更新上下文，不切走UI；list、usage、caption及最后一次Agent show/hide继续缓存。Agent层被临时遮蔽，不能越过本地菜单。菜单退出/超时才撤销owner，app明确恢复最新`screen_for(s_st)`，通知恢复最后请求。迟到的助手状态快照也不能主动关闭菜单。

真实LVGL host测试在菜单显示后注入state/list/keys/caption/Agent更新，前后菜单PNG逐像素相同；退出后分别验证最新通知、会话列表与字幕恢复。

## 两侧微型提示

物理布局依据BSP及应用的PassportIllustration：左上是电源键，右侧从上至下为UP、DOWN、OK，屏幕提示锚点y=70/170/270。BSP只向固件发送右侧三键ADC事件；左边只绘通用电源符号，不宣称软件短按/长按/唤醒行为。

- 右侧主glyph为短按/按住说话含义；同键下方14px的第二glyph附小圆环，表示长按功能。
- 运行模式菜单：上/下箭头、确认对勾；长确认键为返回，未定义的长上/长下留空。
- 独立空闲：上键删除/清历史、下键空、确认键麦克风；长上模式、长下网络列表。
- 独立录音/处理/播放：上键空、下键停止、确认键麦克风（打断重录）；长按模式/网络含义保持入口，由业务检查决定是否允许切换。
- 相伴短按沿用Mac的typed keys缓存；长上本地运行模式，长下原会话/离线网络列表。离线确认键为重新连接。

右侧复用原三个短按label和三个自绘mark，长按图标用已有12px Material字形，圆环为C图元。只新增一个12×14左电源对象，没有新增字体/位图或每帧对象分配。图标和中文caption、宠物主体、时钟不重叠；原生240×320和3倍主机图都已查看。
